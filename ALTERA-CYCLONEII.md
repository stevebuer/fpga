# Altera Cyclone II Board

Ebay EP2C5144C8N minimal board.

<img width="400" src="img/altera_cycloneII.png">

## Device Specs

* 4609 Logic Elements
* 288 Logic Array Blocks
* 119,808 bits RAM 
* 13 (18x18) Embedded Multipliers
* 2 PLL
* 89 User I/O Pins

## Board Specs

* 50 Mhz oscillator
* EEPROM chip
